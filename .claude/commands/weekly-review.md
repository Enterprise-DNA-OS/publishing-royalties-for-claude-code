# weekly-review

Run these and read all of the output:

1. `node scripts/royalties.mjs attention --json`
2. `node scripts/royalties.mjs weekly-review --json`
3. `node scripts/royalties.mjs compliance --json`

Write five short sections: the three things to fix this week, statements and payments owed to authors, the next 60 days of publishing, rights money in and out, and compliance. Save it with `/draft-weekly-review`.
