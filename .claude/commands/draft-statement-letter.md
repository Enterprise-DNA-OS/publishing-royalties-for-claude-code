# draft-statement-letter

Run `node scripts/royalties.mjs draft-statement-letter <statement ref> --json`, read the draft in `drafts/`, and tighten it to the operator's voice. It addresses the author (care of their agent where one is recorded). Never send it: a person sends it with the statement from `npm run docs -- royalty-statement`.
