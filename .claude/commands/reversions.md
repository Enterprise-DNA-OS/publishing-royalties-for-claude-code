# reversions

Run `node scripts/royalties.mjs reversions --json`. Show months out of print against the clause, and sales in the last 12 months. Record a request with `node scripts/royalties.mjs request-reversion <contract> [--date=]` and the reversion itself with `node scripts/royalties.mjs revert <contract> [--date=]` only on the operator's yes. Never decide a reversion: the clause and the operator decide.
