# contracts

With no contract named, run `node scripts/royalties.mjs contracts --json`. For one contract run `node scripts/royalties.mjs card contract <ref> --json`, `node scripts/royalties.mjs rates <ref> --json` and `node scripts/royalties.mjs statements --contract=<ref> --json`, then explain the deal in plain words: share, rates by format and channel, escalators, statement days, reversion clause, and where the account stands.
