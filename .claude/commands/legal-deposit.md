# legal-deposit

Run `node scripts/royalties.mjs deposits --json`. Read the rule in `docs/compliance.md`. Record copies sent with `node scripts/royalties.mjs deposit <edition> [--copies= --date= --library=]`. State and territory libraries in Australia have their own deposit laws: remind the operator, the system tracks the national library only.
